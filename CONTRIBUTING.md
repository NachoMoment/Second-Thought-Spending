# Contributing to Second Thought: Spending

This is a source-visible, owner-moderated project. See [LICENSE.md](LICENSE.md) for contribution and distribution terms. Keep purchase data on the device and avoid adding tracking, accounts, ads, or paid access. Test with invented purchase details.

Run `npm ci`, `npm run build`, and `npm run android:sync` before proposing a change. Test Android service changes on a physical phone. Describe any permission behavior or local-data changes in the pull request.
