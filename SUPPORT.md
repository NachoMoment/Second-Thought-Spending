# Support

Second Thought: Spending is a free, independent app. Start with the [install and update instructions](README.md) and the [latest release](../../releases/latest). For reproducible bugs, use the repository's issues; community replies may be limited. Security reports can be sent privately as described in [SECURITY.md](SECURITY.md).

Do not post real purchase details, product links, exported JSON, or reflection answers publicly. A useful bug report includes the app version, Android version, phone model, and steps using made-up examples.
